10. Étape 8 — Self-Attention causale

Code: src/llm/model/attention.py

Chaque Transformer Block possède :

LayerNorm
    ↓
Self-Attention
    ↓
Residual
    ↓
LayerNorm
    ↓
Feed Forward
    ↓
Residual

L'attention possède :

Q = Query
K = Key
V = Value

avec :

3 heads
×
40 dimensions
=
120 dimensions

Et nous avons utilisé un causal mask.

Donc le token actuel ne peut pas regarder les tokens futurs.

Exemple :

t1 → peut voir t1

t2 → peut voir t1 t2

t3 → peut voir t1 t2 t3

t4 → peut voir t1 t2 t3 t4

C'est ce qui rend le modèle adapté à une architecture GPT-like.
