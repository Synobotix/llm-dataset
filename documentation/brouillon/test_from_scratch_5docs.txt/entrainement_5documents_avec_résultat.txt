Maintenant, on peut transporter le checkpoint pour l'entraîné dans un serveur dédié

Pour pouvoir reprendre student_v1_100docs.pt sur n'importe quel serveur compatible PyTorch, il faut conserver à la fois le checkpoint, l'architecture exacte, le tokenizer et les paramètres d'entraînement.

1. Le plus important : le checkpoint

À conserver :

checkpoints/
└── student_v1/
    └── student_v1_100docs.pt

Ton checkpoint contient déjà :

model_state_dict
optimizer_state_dict
scheduler_state_dict
global_step

Donc il contient l'état nécessaire pour continuer l'entraînement, pas seulement les poids du modèle.

2. Le code du modèle

Il faut conserver le code qui définit exactement ton Transformer :

src/llm/model/
└── transformer.py

Et toutes les classes/fonctions utilisées par Transformer.

Ton architecture actuelle doit rester exactement :

VOCAB_SIZE          = 994
EMBEDDING_DIM       = 120
NUM_HEADS           = 3
FFN_HIDDEN_DIM      = 480
NUM_LAYERS          = 2
MAX_SEQUENCE_LENGTH = 128

Par exemple, si tu modifies :

EMBEDDING_DIM = 256

tu ne pourras pas charger directement le checkpoint actuel, car les dimensions des poids ne correspondront plus.

3. Le tokenizer

Très important :

tokenizer/
└── tokenizer.json

Il faut conserver exactement le tokenizer qui a produit les 994 tokens.

Donc :

tokenizer.get_vocab_size()

doit toujours donner :

994

Il ne faut pas entraîner un nouveau tokenizer pour continuer ce modèle.

Le modèle a appris des poids associés aux IDs de tokens. Si le token 123 signifie autre chose sur le nouveau serveur, le modèle ne fonctionnera plus correctement.

4. Le code du Dataset

Pour continuer l'entraînement, il faut également conserver le code qui transforme les données en :

input_ids
labels

Notamment :

src/llm/data/
src/llm/tokenizer/

et les scripts correspondants.

Le format actuel est :

{
  "input_ids": [...],
  "labels": [...]
}

avec des séquences de longueur maximale :

128
5. Le code du Trainer

Il faut conserver :

src/llm/training/
├── trainer.py
├── checkpoint.py
└── ...

Parce que ton Trainer sait comment :

charger le modèle
       ↓

       ↓
scheduler.step()
